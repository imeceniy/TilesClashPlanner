# Новая карта — подготовительный пакет

Каноническая геометрия снимается с `Схематично.jpg`. Типы объектов и уровни бастионов сопоставляются с `Карта с информацией.jpg`.

- `new-event-map.json` — независимая модель данных и граф соседства для будущей интеграции;
- `new-event-map.schema.json` — контракт формата карты;
- `integration-manifest.json` — запись для будущего каталога карт;
- `preview.html` — интерактивная проверка геометрии и параметров;
- `new-event-map-preview.png` — контрольный статический рендер;
- `../scripts/prepare-new-event-map.py` — воспроизводимый импортёр.

Торговый пост присутствует на карте и даёт `0` меди. Центральная неактивная область называется «Аркадия» и исключена из графа связей и начислений.

Связи вычисляются по общим границам на канонической схеме. Проверка запускается командой `python3 scripts/validate-new-event-map.py`.

Контуры извлекаются в четырёхкратном разрешении и упрощаются без коротких JPEG-сегментов. При повторной подготовке сохраняются стабильные ID территорий и проверенный граф связей, поэтому пользовательские планы не теряют привязки.
