# Tiles Clash Planner — инструкция пользователя

Tiles Clash Planner помогает подготовить понятный план захвата карты для участников союза.

Все изменения сохраняются автоматически в этом браузере. Регистрация и ручное сохранение не требуются.

## Выбор события и карты

Выберите нужное событие в списке «Карта» в верхней панели. На телефоне этот список находится в боковом меню.

У каждой карты собственные планы, союзы, отметки и положение экрана. При переключении данные текущей карты не пропадают: приложение автоматически восстановит их, когда вы вернётесь обратно.

Доступны две карты:

- `Gene Clash · Oil Clash` — карта с восемью фиксированными стартовыми точками;
- `Медь` — новая полигональная карта. Аркадия в центре является декоративной, не выбирается и не приносит награды.

## Быстрый план на новый день

1. Откройте вчерашний план.
2. Нажмите `＋` рядом с названием плана, чтобы создать копию на новый день.
3. Отметьте захваченные территории кистью «Захвачено» — они получат цвет вашего союза.
4. Отметьте территории противников их цветами.
5. Выделите главные цели красным, отметки «1 удар» — оранжевым, а запрет атаки — тёмно-серым.
6. Добавьте направления атаки стрелками или постройте автоматический маршрут.
7. Нажмите «Экспорт PNG» и отправьте изображение участникам союза.

## Управление картой

- Колесо мыши — изменить масштаб.
- Перетаскивание свободного места — переместить карту.
- `Пробел + перетаскивание` — переместить карту независимо от выбранного инструмента.
- Кнопка «Вся карта» — показать карту целиком.
- Кнопка «100%» — вернуть исходный масштаб.
- На телефоне и планшете масштаб меняется жестом двумя пальцами.
- На телефоне карту можно перемещать одним пальцем прямо от территории; короткое касание по-прежнему выбирает территорию.

## Поиск территории

Введите название в поле «Быстрый поиск», например `M30` или `XXL01`.

Выберите результат — приложение приблизит и кратковременно подсветит найденный объект.

## Раскраска территорий

На верхней панели выберите кисть, затем последовательно нажимайте нужные территории:

- «Захвачено» — цвет вашего союза;
- «Приоритет» — красный цвет;
- «Вторичная» — жёлтый цвет;
- «Не бьём» — тёмно-серый цвет для территорий, которые нельзя атаковать; автомаршрут не будет проходить через них;
- «1 удар» — оранжевая отметка для территории, по которой нужно нанести один удар; территория учитывается в планируемых очках;
- «Удержать» — бледно-розовая отметка уже контролируемой территории; её очки учитываются как захваченные;
- «Противник» — цвет выбранного союза противника;
- «Нейтрально» — снять текущий статус;
- «Не учитывать» — исключить территорию из текущего плана и автоматических маршрутов.

В режиме «Выбор» обычный или правый клик по территории открывает меню всех доступных действий.

## Союзы и противники

В разделе «Союзы» можно:

- выбрать активный союз;
- добавить новый союз;
- кнопкой `✎` переименовать союз;
- нажатием на цветной круг изменить его цвет;
- кнопкой `×` удалить союз;
- назначить стартовую точку.

При удалении союза приложение очищает назначенные ему базы, вражеские территории и маркеры во всех планах. Единственный оставшийся союз удалить нельзя.

Перед использованием кисти «Противник» выберите нужный союз. Его территории будут окрашены назначенным ему цветом.

## Стартовые точки

На карте `Gene Clash · Oil Clash` для каждого союза можно назначить одну из восьми точек:

`NW`, `NE`, `W`, `E`, `SW`, `SE`, `SSW`, `SSE`.

Нажмите «Выбрать старт» в карточке союза, затем нажмите нужный цветной круг на карте. После назначения индекс внутри круга заменится коротким названием союза. Свободные точки продолжают показывать `NW`, `NE` и другие географические индексы. Чтобы изменить старт, повторите выбор. Кнопка `×` снимает назначение.

На карте `Медь` фиксированных стартовых кругов нет. Нажмите «Выбрать старт», затем выберите любую активную территорию. Она будет отмечена цветом и коротким названием союза.

## Назначения бастионов на карте «Медь»

У каждого бастиона есть постоянный номер: `Б1.1`, `Б1.2` и далее до `Б6.*`. Первая цифра — уровень бастиона, вторая — его номер внутри уровня. Номера не меняются между планами, экспортами и при назначении союзов. Коричневое обозначение уровней на бастионах заменено нейтральной заливкой, поэтому номер хорошо читается.

Для распределения целей используются два дополнительных инструмента, доступных только на карте «Медь»:

- «Союз» — добавляет к выбранной точке активный союз;
- «Отказ» — добавляет отдельную метку `ОТКАЗ`.

Это независимые метки: одна точка может одновременно быть назначена нескольким союзам и иметь отметку отказа. Повторное нажатие тем же инструментом снимает соответствующую метку. В режиме «Выбор» эти действия также доступны в меню территории.

В боковой панели «Назначения бастионов» автоматически формируется список целей каждого союза и отдельный список отказов. Нажатие на номер в списке переносит карту к точке, а `×` снимает только выбранную метку. Инструменты и статусы карты `Gene Clash · Oil Clash` от этой функции не меняются.

## Крупные названия целей

Чтобы отдельно выделить точку следующего дня, выберите инструмент «Выбор», нажмите нужную территорию и включите «Aa Крупное название». Название станет заметно крупнее и жирнее на карте и в экспортируемом PNG.

Повторите действие, чтобы вернуть обычный размер. Выделение сохраняется отдельно для каждого плана и не зависит от статуса территории.

## Ручные стрелки

1. Выберите инструмент «Маршрут».
2. Нажмите начальную территорию.
3. Последовательно нажимайте следующие территории.
4. Нажмите «Завершить маршрут».

Правый клик по стрелке позволяет изменить:

- начальную и конечную территории;
- цвет;
- толщину;
- пунктир;
- подпись.

Двойной клик удаляет стрелку.

## Автоматический маршрут

1. Выберите союз, для которого строится маршрут.
2. Назначьте этому союзу стартовую точку.
3. В разделе «Автомаршрут» выберите конечную цель из списка или нажмите «Выбрать на карте».
4. Нажмите «Найти путь».
5. Сравните предложенные варианты. Для каждого указано количество новых и вражеских территорий.
6. Выберите подходящий вариант и нажмите «Добавить как маршрут», чтобы превратить его в стрелки.

Маршрутизатор отдаёт предпочтение уже захваченным территориям. Вражеские территории считаются более дорогими, а объекты со статусом «Не учитывать» полностью исключаются из пути.

Жёлтые кольца показывают территории, которые необходимо пройти предварительно, зелёное — конечную цель. Недоступные территории отмечаются красными перечёркнутыми кольцами.

Блок «Рекомендуемые цели» сравнивает доступные верстаки по эффективности и количеству ещё не захваченных территорий на пути. Нажатие рекомендации сразу строит маршрут к выбранной цели.

Территории со статусом «Не учитывать» исключаются из поиска пути. Если маршрут не найден, снимите этот статус с нужных промежуточных территорий или выберите другую цель.

## Текст и маркеры

Инструмент «Текст» добавляет произвольную подпись на карту. Подпись можно перетаскивать, а двойным кликом — изменить её текст, размер и цвет.

Инструмент «Маркер» добавляет крупный маркер активного союза. Маркер можно перетаскивать и удалить двойным кликом.

Через меню территории также можно добавить отдельную заметку.

## Стратегическая информация

Под панелью инструментов постоянно показываются две суммы:

- «Уже захвачено» — очки всех захваченных территорий;
- «С планируемыми целями» — очки захваченных, красных и жёлтых территорий вместе.

Вражеские, нейтральные и исключённые территории в эти суммы не входят. Значения пересчитываются сразу после изменения статуса.

Для новой карты дополнительно показывается добыча меди в час. «Уже захвачено» суммирует добычу захваченных и удерживаемых объектов, а теоретическое значение добавляет планируемые цели и территории с отметкой «1 удар».

Переключатель «Стратегическая информация» показывает на объектах:

- количество очков, которое территория даёт после захвата;
- относительную эффективность верстака: `S/M/L — ×1.00`, `XL — ×1.67`, `XXL — ×3.33`.

Актуальные очки территорий:

- логова: `XS — 100`, `S — 200`, `M — 375`;
- верстаки: `S — 300`, `M — 400`, `L — 600`, `XL — 1000`, `XXL — 2000`.

На карте нового события:

- первый захват бастионов: `1 ур. — 200`, `2 ур. — 400`, `3 ур. — 600`, `4 ур. — 800`, `5 ур. — 1000`, `6 ур. — 1500`;
- добыча меди: `деревня — 1/ч`, `завод — 3/ч`, `городок — 10/ч`, `мегаполис — 15/ч`, `центр исследований — 25/ч`, `военная база — 50/ч`;
- торговый пост и Аркадия не дают очков или меди.

Стоимость захвата в приложении не отображается.

Для обычной подготовки плана этот режим можно оставить выключенным.

## Планы по дням

В разделе «Проект» доступны действия:

- «Новый пустой» — создать план без отметок;
- «Копировать день» — полностью скопировать текущий план;
- «Переименовать» — изменить название;
- «Удалить текущий день» — удалить выбранный план;
- «Сбросить текущий план» — очистить его содержимое.

На компьютере быстрое копирование дня также выполняется кнопкой `＋` рядом с названием текущего плана.

## Отмена действий

- `Ctrl+Z` или кнопка `↶` — отменить действие.
- `Ctrl+Y` или кнопка `↷` — повторить отменённое действие.

## Отображение карты

В боковой панели можно отдельно включать и выключать:

- названия и значения объектов;
- стратегическую информацию;
- территории противников и нейтральные территории;
- стрелки и исходные связи карты;
- подписи и маркеры;
- легенду при экспорте.

Эти настройки не удаляют данные, а только временно скрывают их.

## Экспорт и передача проекта

«Экспорт PNG» сохраняет полную карту с текущими цветами, стрелками, подписями и маркерами. Для карты с логовами над картой крупно выводится напоминание «ЛОГОВА ВСЕГДА БЬЕМ ПЕРЕД СНОМ». Справа добавляется отдельная колонка с названием дня, фактическими и теоретическими очками, добычей меди и легендой статусов. На карте «Медь» в легенду также входят метки союзов и «ОТКАЗ»: под каждой меткой перечислены номера всех назначенных территорий. Если список не помещается по высоте карты, экспорт автоматически расширяет правую колонку, не обрезая данные. Легенда не перекрывает карту.

«Копировать карту как PNG» помещает изображение в буфер обмена, чтобы его можно было сразу вставить в Discord или Telegram.

«Экспорт PNG высокого качества» создаёт файл с разрешением до 3600 пикселей по большей стороне. Используйте его для отправки в мессенджеры с возможностью увеличения или печати; обычный экспорт и копирование остаются быстрее и экономнее для телефона.

«Экспорт JSON» сохраняет редактируемый проект со всеми днями и союзами. Другой офицер может открыть его через «Импорт JSON».

«Ссылка только для просмотра» создаёт ссылку на текущий план и копирует её в буфер обмена. Получатель сможет перемещать и масштабировать карту, менять отображение и экспортировать PNG, но не сможет изменить исходный план. В ссылку включается только открытый день, без истории остальных планов.

При импорте текущий проект заменяется импортируемым, поэтому перед импортом рекомендуется сделать экспорт JSON текущего состояния.

## Совместная работа

Кнопка «Команда» открывает серверные проекты. Локальными планами по-прежнему можно пользоваться без аккаунта.

1. Зарегистрируйтесь или войдите в существующий аккаунт.
2. Создайте общий проект либо откройте проект, к которому вас добавил R5.
3. Изменения R4 и R5 автоматически отправляются в общий проект. Открытые у других участников копии обновляются в реальном времени.
4. Если одновременно появились несохранённые локальные и серверные изменения, приложение предупредит о конфликте и предложит сначала загрузить актуальную версию.

Роли проекта:

- `R5` — редактирует карту, управляет участниками и их ролями, возвращает прежние версии;
- `R4` — редактирует карту и может возвращать прежние версии, но не управляет составом;
- `MEMBER` — только просматривает общий проект.

В разделе «История» хранятся последние версии проекта с автором и временем изменения. Возврат версии не стирает историю: он создаёт новую ревизию на основе выбранной.

Кнопка «Короткая ссылка» создаёт постоянный адрес только для просмотра. План в такую ссылку не встраивается: получатель загружает актуальную серверную версию по короткому идентификатору. Если общий проект не открыт, обычная кнопка передачи продолжает создавать прежнюю автономную ссылку в адресной строке.

## Автоматическое сохранение

После каждого изменения в верхней панели появляется состояние «Сохраняем…», затем «Сохранено».

После обновления страницы сохраняются планы, статусы, союзы, стрелки, подписи, стартовые точки, масштаб и положение карты.

Данные хранятся в текущем браузере. Если очистить данные сайта или перейти на другое устройство, используйте экспорт и импорт JSON.

## Работа на телефоне

Нажмите кнопку `☰`, чтобы открыть боковую панель. В ней доступны поиск, союзы, автомаршрут, настройки отображения, планы, импорт, экспорт и эта справка.

Для закрытия панели нажмите `☰` повторно или коснитесь карты.
